# AI Librarian: ระบบแนะนำหนังสืออัจฉริยะโต้ตอบด้วยเสียง

## 📖 ภาพรวมโครงการ

AI Librarian คือเว็บแอปพลิเคชัน Full-stack นวัตกรรมใหม่ที่ออกแบบมาเพื่อปฏิวัติวิธีการค้นหาและโต้ตอบกับหนังสือของผู้ใช้ห้องสมุด ระบบนี้มีผู้ช่วยบรรณารักษ์ AI ชื่อ **"ไลท์" (Lite)** ที่คอยให้คำแนะนำหนังสืออย่างชาญฉลาดและพูดคุยทั่วไปได้ผ่านระบบโต้ตอบด้วยเสียง

เหนือกว่าการค้นหาด้วยคำสำคัญแบบดั้งเดิม AI Librarian ใช้เทคโนโลยี AI ขั้นสูงรวมถึงสถาปัตยกรรม **RAG (Retrieval-Augmented Generation)** เพื่อให้คำแนะนำหนังสือที่แม่นยำและเข้าใจบริบทตามคำค้นหาภาษาธรรมชาติ ช่วยลดปัญหาการ "มั่วข้อมูล" (Hallucinations) ของ AI และรับประกันความถูกต้องของข้อมูล

โครงงานนี้ถูกพัฒนาขึ้นด้วยความภาคภูมิใจเพื่อเป็นโครงงานจบภาคการศึกษาสำหรับสาขาวิชาเทคโนโลยีคอมพิวเตอร์

## ✨ คุณสมบัติหลัก

-   **📚 ระบบสนทนาสองโหมด (Dual-Mode Conversation):** มีโหมดการสนทนา 2 รูปแบบเพื่อตอบโจทย์ความต้องการที่แตกต่างกัน:
    -   **โหมดหนังสือ (Book Mode):** ใช้สถาปัตยกรรม RAG เพื่อให้คำแนะนำหนังสือที่แม่นยำจากคลังความรู้
    -   **โหมดคุยเล่น (Chat Mode):** โหมดสนทนาทั่วไปสำหรับหัวข้ออื่นๆ นอกเหนือจากหนังสือ โดยใช้ความรู้ทั่วไปของ LLM
-   **🗣️ การโต้ตอบด้วยเสียงและข้อความ:** โต้ตอบกับ AI ได้อย่างราบรื่นทั้งการใช้คำสั่งเสียง (ผ่าน Web Speech API) และการพิมพ์ข้อความ
-   **🧠 สถาปัตยกรรม RAG:** ใช้สถาปัตยกรรม Retrieval-Augmented Generation (RAG) ที่แข็งแกร่ง เพื่อให้คำตอบที่อ้างอิงจากฐานความรู้ที่คัดสรรมาแล้ว ลดการมั่วข้อมูลและรับรองความถูกต้อง
-   **🔍 การค้นหาเชิงความหมาย (Semantic Search):** ค้นหาหนังสือจาก *ความหมาย* และ *บริบท* ของคำถามผู้ใช้ แทนที่จะจับคู่แค่คำสำคัญ ขับเคลื่อนโดย FAISS vector store ที่มีประสิทธิภาพสูง
-   **🌐 รองรับสองภาษา:** ออกแบบมาให้เข้าใจและตอบโต้ได้ดีทั้งภาษาไทยและภาษาอังกฤษ พร้อมระบบตรวจจับภาษาอัจฉริยะและเลือกเสียงอ่าน (TTS) ที่เหมาะสม
-   **🚀 การผสมผสานโมเดล AI:** ใช้ Groq API อย่างชาญฉลาดเพื่อการตรวจจับภาษาและความเข้าใจเบื้องต้นที่รวดเร็ว ผสานกับ Google Gemini API เพื่อการสร้างคำตอบที่มีคุณภาพและละเอียดอ่อน
-   **🎙️ โหมดเสียงต่อเนื่อง (Continuous Voice Mode):** มอบประสบการณ์การสนทนาแบบไม่ต้องใช้มือ (Hands-free) โดยหลังจาก AI พูดจบ ระบบจะกลับมาฟังเสียงผู้ใช้โดยอัตโนมัติเพื่อการสนทนาที่ต่อเนื่อง
-   **🎨 UI ที่ทันสมัยและรองรับทุกอุปกรณ์:** หน้าตาโปรแกรมที่สะอาดตา ใช้งานง่าย พร้อมปุ่มสลับธีมสว่าง/มืด, ตั้งค่าภาษา, ควบคุมการเล่นเสียง และอื่นๆ

## 🛠️ เทคโนโลยีที่ใช้

-   **Backend:** Python, Flask, LangChain, Gunicorn (สำหรับสภาพแวดล้อมคล้าย Production)
-   **AI & Machine Learning:** Google Gemini API, Groq API, FAISS (Vector Database), `sentence-transformers` (สำหรับ embeddings), `edge-tts` (สำหรับ Text-to-Speech)
-   **Frontend:** HTML5, CSS3, Vanilla JavaScript, Web Speech API (สำหรับ Speech-to-Text และ TTS ของเบราว์เซอร์), `marked.js` (สำหรับการแสดงผล Markdown)
-   **Database:** JSONL (สำหรับเก็บข้อมูลหนังสือดิบ), FAISS (สำหรับ indexing เวกเตอร์ประสิทธิภาพสูง)
-   **Development & Deployment:** Python `venv`, Git, GitHub, VS Code

## 🚀 การเริ่มต้นใช้งาน: การติดตั้งและตั้งค่า

ปฏิบัติตามขั้นตอนละเอียดเหล่านี้เพื่อติดตั้งและรันโปรเจค AI Librarian บนเครื่องของคุณ

### สิ่งที่ต้องมีเบื้องต้น

ก่อนเริ่มใช้งาน ตรวจสอบให้แน่ใจว่าคุณได้ติดตั้งสิ่งเหล่านี้แล้ว:

1.  **Python 3.12+**: ดาวน์โหลดและติดตั้งจาก [python.org](https://www.python.org/downloads/) อย่าลืมติ๊ก "Add Python to PATH" ระหว่างการติดตั้งบน Windows
2.  **Git**: ดาวน์โหลดและติดตั้งจาก [git-scm.com](https://git-scm.com/downloads)
3.  **Command Line Access**: ความคุ้นเคยกับการใช้เทอร์มินัลของระบบ (Command Prompt/PowerShell บน Windows, Terminal บน macOS/Linux)
4.  **(แนะนำสำหรับผู้ใช้ Windows)** **WSL 2 (Windows Subsystem for Linux)** พร้อม Ubuntu distribution เพื่อความเข้ากันได้และประสิทธิภาพที่ดีที่สุด
    * **วิธีติดตั้ง WSL 2 & Ubuntu:** เปิด PowerShell ในฐานะ Administrator แล้วรันคำสั่ง `wsl --install` ทำตามคำแนะนำบนหน้าจอและรีสตาร์ทคอมพิวเตอร์ ติดตั้ง Ubuntu จาก Microsoft Store หากไม่ได้ติดตั้งให้อัตโนมัติ อัปเดต Ubuntu ด้วยคำสั่ง: `sudo apt update && sudo apt upgrade -y`
